# 🎮 Rock Paper Scissors Game

A fun, interactive, and beginner-friendly Rock Paper Scissors game built using **HTML, CSS, and JavaScript**.

Play against the computer, make your choice, and see who wins! The computer randomly selects Rock, Paper, or Scissors, and the game automatically determines the winner while keeping track of the scores.

## ✨ Features

- Three interactive choices: Rock ✊, Paper ✋, and Scissors ✌️.
- Computer generates a random choice.
- Automatically detects win, lose, and draw results.
- Live score tracking for both the player and computer.
- Displays both players' choices after every round.
- Reset button to restart the scoreboard.
- Simple and attractive user interface.
- Responsive design for mobile and desktop screens.

## 🛠️ Technologies Used

- **HTML5** – Creates the game structure.
- **CSS3** – Adds styling, colors, layouts, and responsive design.
- **JavaScript** – Handles game logic, random choices, events, and score updates.

## 🎯 Game Rules

- Rock beats Scissors.
- Scissors beats Paper.
- Paper beats Rock.
- If both players choose the same option, it's a draw.
